# ef-social-images

Public image host for EastFrontier's scheduled social media posts. Buffer fetches each post's image from here when the post is created or published.

- Only images (PNG) and LinkedIn carousel PDFs, at the same path as in the private archive **ef-social**: `YYYY/MM/DD/<Platform>/<file>`.
- Image address: `https://raw.githubusercontent.com/EastFrontier/ef-social-images/main/YYYY/MM/DD/<Platform>/<file>`
- Everything here is published on X, LinkedIn and Facebook the same day. Nothing else belongs in this repo.
- Old days may be removed once all their posts have gone out; the full record stays in ef-social.
